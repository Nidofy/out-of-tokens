### 任务 1：`VF11-F-01`（P2 必做）——校准 S3 晚间/深夜在岗伙伴日常互动忙碌判定，并恢复准确命名的普通日程 `recall` 入口
- **涉及文件**：`apps/web/src/alpha-app.tsx`（及本轮抽出的伙伴档案组件）。
- **问题根因与复现**：
  1. 在 `?office-lab=standard&animation-time=1` 下点击两次「下一时段」进入 `第1天 · 晚上`（`slot = 2`），Qwen 处于 `working` 委托队伍中但未加班，按日程前往图书馆。点击「去找伙伴」到达图书馆后打开 Qwen 档案，因 UI 对「聊天 / 送礼 / 吃饭 / 学习」直接使用了 `actor.busy`（即 `occupied(s, a.id)`，只要挂在活跃委托队伍中全天 4 槽皆为 `true`），导致晚间下班在图书馆的 Qwen 仍显示“正在负责委托工作，空闲后可聊天”且无法聊天、吃饭（恢复精力/降饥饿）、送礼或学习。而 `packages/oot-core/src/campaign.ts` 第 101、114 行的真实规则是 `check(!assigned || s.absoluteSlot % 4 >= 2, 'ACTOR_BUSY')`——即在岗伙伴仅在白天工作时段（`slot % 4 < 2`）、已安排本槽加班（`overtime.includes`）或本槽已有个人活动（`busyUntil > absoluteSlot`）时才不能进行日常互动。
  2. VF1.1 移除错误远征召回后，非远征时的普通日程 `recall`（`campaign.ts` 第 115–116 行：将晚间在食堂/图书馆的伙伴请回工作室 1 槽，要求同场景当面或已安装 `remote` 软件）在档案折叠区失去了入口。
- **修复目标**：
  1. 在不动 `packages/oot-core` 的前提下，在前端状态派生中明确区分：
     - **派遣/澄清占用**：`actor.busy`（继续用于 S2 候选卡占用提示、澄清按钮与版本切换/训练锁定）；
     - **当前时段日常互动忙碌（`lifeBusy`）**：`const lifeBusy = actor.busyUntil > view.absoluteSlot || view.overtime.includes(actor.id) || (activeJobs.length > 0 && view.absoluteSlot % 4 < 2);`
  2. S3 首屏 `.profile-status`、首屏「聊天」按钮、以及折叠区「送礼 / 吃饭 / 学习」按钮改用 `lifeBusy` 替代 `actor.busy`：
     - 当 `!onExpedition && sameScene && !lifeBusy && activeJobs.length > 0 && view.absoluteSlot % 4 >= 2` 时，可不显示阻塞提示或显示温和说明（如 `"当前为晚间休息时段，可聊天、互动或安排本槽加班。"`），且允许正常点击同场景「聊天 / 送礼 / 吃饭 / 学习」；
     - 一旦玩家点击了「本槽加班」（`view.overtime.includes(actor.id)` 为真）或执行了一次日常互动（`actor.busyUntil > view.absoluteSlot` 为真），`lifeBusy` 立即变为 `true`，上述日常按钮与「本槽加班」同步禁用（完全符合 `campaign.ts` 与 `simulation.ts` 的互斥规则）。
  3. 在 `<details>互动与日程</details>` 的 `.button-row` 中，当 `!onExpedition` 时恢复普通日程召回按钮，命名为 **「请回工作室 / Recall to workshop」**，禁用条件严格对齐 `campaign.ts` 第 101、114–116 行：
     - `disabled={locked || lifeBusy || actor.location === 'workshop' || (!sameScene && !p.software.includes('remote'))}`；
     - `onExpedition` 为真时继续显示禁用的「远征中，等待返程 / On expedition; awaiting return」按钮；
     - 更新折叠区说明文案，简明交代「请回工作室需伙伴在食堂/图书馆且同场景（或已研发远程协作）」。
- **验收条件**：
  - `standard` 夹具推进 2 槽到 `第1天 · 晚上`，点「去找伙伴」到图书馆后，Qwen 的「聊天 / 送礼 / 吃饭 / 学习 / 请回工作室」均可用，点击任一动作成功且不报错；
  - 若先在晚上对 Qwen 点击「本槽加班」，Qwen 立即回到工作室加班，`lifeBusy` 为真，「聊天 / 送礼 / 吃饭 / 学习 / 请回工作室 / 本槽加班」全部禁用。
