## 像素与复现

1. 使用 Python 3.14.0、Pillow 12.1.1、libwebp 1.6.0、NumPy 2.3.5 和 SciPy 1.18.1，在仓库根目录连续两次运行 `python -B scripts/export-art-batch12a.py`。逐一比较 18 张母版、18 张 WebP、运行时索引、批次清单及 7 张核验图，45 个文件的 SHA256 全部一致。全部输入来自仓库。[导出脚本](../../scripts/export-art-batch12a.py)
2. Pillow 解码后，18 张图的 alpha 极值均为 `[0, 255]`，所有 alpha 大于零的像素中纯黑数均为 0。12 张立绘可见高度均为 920px，顶部留白 104px，左右最小留白 31px，包围盒下界为 1024。头像四边最小留白 12px，左右瞳心各自的纵坐标均在 122.86–135.98px。另用像素中心独立复算了全部 18 个头部质心，与索引一致。[原图标定](../../art/art-batch-12a/composition.json)
3. 初次以质量 88 直接编码的 Bluewhale 日常版为 177,124 字节。最终立绘以质量 86、方法 6 编码，封实接近不透明的衣料，只按需平滑内区的纸纹，保留眼周与外轮廓。头像使用质量 88。逐图的编码参数已记录在清单内。导出时先在临时目录完成全批检查，再通过目标目录内的临时文件原子替换，解决 Windows 移动文件继承私有临时目录权限的问题。
4. `pnpm check` 的类型检查、lint、56 个测试文件中的 515 项测试及 Web、DSH 生产构建均通过。另运行 `pnpm vitest run apps/web/package-verification.test.ts`，25 项通过。两个发行目录的离线清单均包含 18 张 WebP 和 1 份索引，发行副本的 SHA256 与公共源文件逐项一致。[离线包验证](../../apps/web/package-verification.test.ts)
5. `git diff --check` 和暂存区空白检查通过。相对基线核对了 `packages/`、`content/`、五个受保护公共美术目录以及基线中的历批美术归档，差异数为 0。Web 源码差异只有新增的纯路径白名单模块。
