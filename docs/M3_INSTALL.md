# M3 本地测试安装说明

这是实验工程包，经营门禁M05-03未关闭。真实DSH共存/卸载尚未验收；本轮没有安装进用户正在使用的DSH，没有修改小院worktree或Profile。

推荐先使用试玩包根目录的start.cmd（Node24），浏览器打开http://localhost:4173。保持同一来源地址以找到原IndexedDB档案；更新前导出JSON。无需pnpm、联网下载或真实模型API。

DSH候选包在dsh/。package.json的入口是dist/index.js和dist/client.js，cordis.patch.yml仅注册out-of-tokens服务；所有运行时代码与内容已打包，不依赖原仓库node_modules。目标宿主契约为DSH0.2.1-rc.5。先在另建的可丢弃DSH Profile中，用该版本的本地插件管理入口导入这个目录；此步骤需真人或后续明确授权的真实宿主验证，本轮没有代为执行。卸载通过宿主插件管理器进行，不手动删除用户存档。存档保留在该Profile下out-of-tokens/v1/slots.json；与小院owner隔离。

工坊入口：小院地图.village-community-map内button[data-place="workshop"]。当前小院没有公开扩展注册API，因此以可卸载的捕获监听适配已核对的地图结构；另有会话角落/浮动备用入口。小院改DOM时需复核，不承诺跨任意版本兼容。

卸载前点击“保存并关闭”。正常关闭需要iframe确认自动档；失败保留面板以供载入对账或导出。强制关闭宿主无法保证未确认的内存状态；每条有效游戏命令在Host模式下都会尝试保存，已开始的文件事务由服务端等待完成。网络结果不确定时不自动重试写入，先读取最新档对账。

最小真实宿主验收：新Profile加载插件和小院→两入口打开→推进/手存/刷新恢复→第二窗口冲突→断连重连→关闭面板→卸载服务与客户端→小院地图/角色/原存档仍正常→重新安装后读取原工坊档。只使用可丢弃数据。验证后记录DSH版本、完整插件SHA、截图和失败日志；契约测试不替代此项。

只读联动目前限于一致的12角色ID及许可允许的PaperDoll代码复用。没有读取小院世界存档、纪念物、会话或真实Token用量；纪念物公开只读协议和真实用量彩蛋后续再设计。
