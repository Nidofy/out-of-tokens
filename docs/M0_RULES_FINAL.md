# M0.3实施规则与范围
该文件覆盖M0_SPEC中的首切片限制，GDD原文不变。

## 内容与工作流
4初始角色、30委托（6类别、4甲方、oneshot/multi/retainer）、20事件。
工作量/报酬按每阶段计；一次性1阶段，多轮2阶段，长期3个周阶段。仅首次30%预付；阶段验收结清后预付清零，下阶段独立质量/返工/期限，已付阶段不重复退款。
长期下阶段从前周期开始+28槽开始；等待保留岗位占用、不收费，形成机会成本。
每天5单。SLA/竞标不在M0，schema拒绝。澄清一槽固定揭示一条；返工一次+20%WP并清除已确认的隐藏/缺陷扣分，未声称实现全部隐藏标签。

## 20卡的可执行改编
可达条件过滤→按权重选择一张→保存card/job/slot→选项效果→结算一次；冷却12槽可配置。每卡都有免费退出选项。
效果白名单：工作量、质量、缺陷、心情、压缩上下文、重置进度、Token倍率、资金比例损失，不执行任意代码。
每卡只影响目标委托；busy仅作用DeepSeek云端，本地免疫。
20卡对应GDD§8.2的1–20主题；四开源阶段改编如下：
- 深想/啊哈用研究类触发，无R1，奖励计入本阶段质量。
- 429/降智用共享云服务触发，无闭源；降智用本阶段质量扣分，不伪装跨槽全家族debuff。
- 拒答/谄媚/注入/奶奶漏洞用小白客户需求或附件触发，选择影响质量/费用。
- 循环用multi/retainer触发，三倍消耗仅当前槽，可中断换停工；删库选择直接执行清零进度。
- 改测试改为当阶段缺陷，尚无维护期爆雷；回滚选择降速恢复或新增8WP；小改选择拒绝降速或新增8WP。
- 数字/拼写题是可选答案的迷你题，正确免罚，错误+1缺陷。
- 其余卡提供核查/停工/付费或冒险效果。逐卡测试覆盖条件和全部选项，非纯文本填数量。
M1/M2对应角色/维护系统加入后再恢复特殊版本细节。

## 经济、危机、重开
5000启动、slot56记8000旧债；连续每12槽负现金记一次危机，112槽内3次或现金<-20000破产。
两次危机声望×0.8；负现金日结心情-5，只接<=40WP小单。
贷款上限5000，周息5%，本金由repay偿还；周费2300另加本地电费与利息。临时T跨日保留。
restart只在破产后允许，保留图鉴和累计创始人经验（本局最高声望/10取整），其他经营状态重置。M0仅标准难度；没有天赋购买、设备售卖、对手挖角或剧情，交M1/M2。
晚间/深夜overtime指定角色仅当前槽有效，精力-18/-22.5，心情-10/-20。未加班者休息，深夜清上下文。
