# M0 实施口径（M0.0–M0.2 验收版；经济数值 Provisional）
以下规则与 GDD 差异见 DECISIONS。不是完整 M0 验收声明。

1. 时钟：absoluteSlot 从 0 开始，每天上午/下午/晚间/深夜；仅前两时段默认工作。截止为第 N 个标准工作时段的结束边界（0 起 6 工作时段截止 10）。日结在新 slot %4=0，周结 %28=0，截止当时段结算后判断。
2. 事件：prepare→selectEvent→pendingChoice→resolveOnce。待选时禁止其他模拟命令。选项影响当前待结算时段；保存整个日志可重建 RNG 游标及未决事件。重复 choice 失败。
3. 岗位：Worker 才累积交付 WP；Planner 只提供推理×1.5%加速，Reviewer 只提供审查。首切片禁止兼岗，一人仅占一个委托/澄清行动；角色固定一个激活版本。
4. Token：云配额每日重置，购买余额跨日保留，先扣配额。local 能力在版本上声明；本地容量每时段重置，消耗按0.1元/单位累入电费。资源不足整名角色停工，不自动切换或部分计费。
5. 版本：四个初始版本来自§5.4。切换及蒸馏首切片拒绝；以后设计培训。
6. 质量：按累计有效 WP 加权匹配×100，+实际审查匹配×10，−8×隐藏需求−6×缺陷，最后一次种子波动[-5,5]，钳制0–100，所有小数保留2位。审查检出缺陷增加5WP。未达标允许一次额外20%WP返工并清除隐藏/缺陷扣分，仍须期限内完成。奖励档1/1.15/1.35，扣除已经付的30%预付。
7. 委托：首次仅 oneshot；其他类型 schema 明确拒绝。预付30%，违约退预付+30%罚金。超过截止50%宽限自动违约；逾期每绝对时段收入−10%，最少0。无 SLA 或维护期结算，待扩展。
8. 验收：首切片4角色、少量模板/事件和CLI闭环；M0.3 才30模板/20卡。M0覆盖四角色派遣；12角色≥3%及旗舰贪心正式指标延至M2。
9. 经济：5000启动、8000欠费于slot56扣除；初始300T，第3天600T，周租1200+电费100+订阅1000；现金可负，负现金持续12时段或低于−20000破产（临时简化）。贷款/债务螺旋/重开未实现。不得据此声称§16.8平衡达标。
10. 异常：unknown命令运行时校验；失败原对象返回、无事件。引擎版本+内容版本+内容指纹+seed+Command数组是存档协议；重放校验最终hash，未知版本拒绝。无旧版存档，暂无迁移函数。

规则测试按 clock/core/persistence 文件及 CLI smoke 对照；每个新增实现须补对应验证。

首切片额外限制：澄清固定揭示一条并占角色到下一槽；没有期限前下调工作量。
不开加班，不支持深度/协同/谈判/换版本，均不暴露对应Command。
事件为工作时段25%抽取，busy仅在bluewhale云端派遣时可抽取，免费等待只暂停该角色云端，或付80元恢复；tip当槽全队1.2倍。每张卡至少有免费选项。
固定按planner→worker→reviewer、同岗角色ID的ASCII次序执行；只有实际付费的planner产生加速；审查逐个检测当槽结束时的缺陷。
本地每槽120容量，资金账本允许危机负值；额度不足不支付也不产出。
RNG采用混合种子+xorshift32独立流，不改变GDD原文，见D015。
资源流水记录slot/job/character/mode/units/quota/purchased/electricity，现金流水独立；tokensUsed当前是云+本地等价资源总量，不应误认为纯云消费。
引擎0.2.0、内容m0.2-2：改变审查顺序与事件作用域，旧0.1.0存档明确拒绝，请在历史检查点打开；不静默迁移。
