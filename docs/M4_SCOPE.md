# M4 扩展实施边界

2026-11-07，用户确认按GDD实施M4/M5两大版本；渠道化是发布准备，不替换M5完整版战役。GDD原文不改。工程实施继续，经营M05-03、真人0/10、真实DSH验收保持开放，不把主线程整改当外部批准。

M4采用PC/Tauri路线，不做微信或Steam发布。前端嵌入离线资源、独立应用标识与WebView存储，不访问实际DSH Profile。Tauri版本使用本机缓存2.11.5/tauri-build 2.6.3，配置参考 https://v2.tauri.app/reference/config/ 。以真实离线编译结果判定构建，不将源文件存在当构建成功。

氛围层使用原创语料训练的字符bigram微型模型（KB级），Web Worker执行，500ms超时/异常回模板。没有下载神经模型、WASM权重或调用真实API；这与GDD允许的KB语法/n-gram层一致，MB神经模型仍为可选后续。输出不接触Command、RNG和账本，纯文本渲染。开关默认关闭。

内容包首个可用格式为schemaVersion=1的对话包，id/version/engine/author/license/lines，大小64KB、100行，ID自动命名空间，拒绝未知字段、HTML/URL、重复ID、不兼容版本。可导入/卸载，失效保留现有包；仅内存启用，不写入经营档。访客角色/委托/场景资源包仍需独立schema扩展，不能把对话包宣称为完整联动格式。

M5按GDD增加第3–4章、五种结局、无尽周挑战、对手竞标和异世界远征。所有数值为实验规则，先写决策与回归，不借用M0统计成绩放行。
