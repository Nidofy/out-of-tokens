# M5 实验规则与 GDD 取舍

2026-11-07。引擎0.10.0，内容m5-1；M2历史loadAlphaContent仍为m2-1。所有旧引擎存档明确拒绝，不猜测迁移。用户确认按GDD推进M4、M5；下列具体阈值为工程实验决策，并非已验证平衡。

- 第3章“429危机”：声望≥20、净偿付资金≥4000、网络≥2级、赢过一次竞标。第4章“最后一个Token”：两种远征纪念物、研发≥30、净偿付资金≥6000。第0–2章目标保持，逐章领取，最高4章。
- 新增8个仅第3/4章可见的双语委托、4个章节事件，共108委托/64事件。章前不能抽取，不以填充数量宣称谜题质量。
- 第4章后选择一次结局：独立（净资金12000/声望30）、收购（完成第4章）、开源（所有开源角色已招募且好感85）、小店（12人全员好感65）、回形针（纸片纪念物，已过112槽，近112槽交付≥28次，全员好感<25）。回形针条件是“连续追求利润”可检验的实验代理，不声称可直接测量玩家动机。选择后冻结经营；显式进入无尽后恢复。没有结局现金奖励或重复领取。
- 无尽每28槽轮换：版本单价≤8 / 全员本地 / 基础上下文≤6。新增派遣与原有团队实际产出均检查。只统计进入无尽后本周新委托，质量≥75交付3单，领取5RP每周一次。周切换不会清债、回满资源或重置合同。
- 远征第3章开放。史莱姆/城堡/纸片分别8/12/16槽、费用120/240/480、研发3/7/12；出发扣20精力且需至少30精力。空闲角色离岗，不能兼任工作或加班。按游戏时段推进，返回自动发奖一次；重复目的地可获得研发但纪念物去重。不使用真实离线时钟。没有跨存档或真实小院经济转账。
- 竞标第2章开放：每单一次60元、明示确定性条件，失败移除合同，胜出仍需自行接单。卷王路线需无隐藏需求/声望10，报酬85%；精品需声望20/研发10，报酬115%；套壳救援需小白客户/无隐藏需求，报酬150%。预付款与最终交付使用同一倍率。当前是合同层对手，不宣称实现自主对手经营、挖角或低15%递归竞价；它们保留为GDD扩展缺口。
- 60剧情为新的角色分线双语草稿，各段标题、正文、选择可区分，英文不含中文首句。由主实施线程编写，未经人工编辑；不冒充GDD“全部人工撰写”的已验收内容。M2历史内容原样保留。
- 本地算力仍按槽，不静默切换GDD的按天单位（M3-06开放）。经济P1仍阻塞经营放行；新增系统不借用历史M0统计成绩。
