# VF4 准备：推广清单与逐批验收门禁

2026-11-10，承接 VF3.1。本文是可供审核的后续计划，**未执行 VF4 组件推广或资产生产**。当前实现/证据入口为 VF3_CHECKPOINT.md 的 VF3.1 节及 harness/reviews/vf31-handoff.md。用户附件只明确授权三项收尾修复；标题中的“受控进入 VF4 准备”不扩张为批量重绘授权。

## 1. 已定方向与仍需裁决的边界

- 继续温暖现代 AI 工作室：暖木场景、暖白/深褐纸面菜单、深胡桃工具、黄铜细饰；装饰金色不承担焦点语义。现代系统无衬线、tabular-nums、蓝色双焦点环沿用 VF2。不新增字体依赖或全站换肤。
- S1 场景优先与紧凑经营摘要、S2 桌面三栏/手机分步与固定确认、S3 大头像/身份/现状/可用操作沿用。普通浮层不移动场景；定位、布置预览有独立镜头，退出布置恢复原 S1。
- 角色母版与骨架、12Q身份服饰、1920×1080世界、固定槽位、完整电脑套餐、前后遮挡和精确命中继续保护。standard 保持单屏；Tier2/3 不在本轮扩产。
- 反馈按对象归属且只有一个主回执。局部关闭即结束；派遣/交付可回 S1；全局存档告警需明确确认或恢复。不得用新弹幕/横幅再次播报同一事件。
- **尚未定案**：完整走近/入座/接触/离开动作、十二体型全部姿态光影、全章节背景一致性，以及低端机/输入/离线/200%文字预算。VF3的共享几何与42次命中证据不等同于这些完成。
- **性能门禁开放**：本轮 dev twelve 确认批次相对 VF3 +24.37%；旧 VF3 dev standard 波动也未解释。优化 preview 相对 VF3 在 -13.84%～+1.59%之间，不能替代完整性能裁决。
