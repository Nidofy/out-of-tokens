## 1. 结论与范围

**方向接受，完成度不能按“Phase 1–3 全量落地”验收。** 暖色材质、主行动实心化、纸面弹窗、家具软阴影和工位预估强化解决了真实问题。CSS 换皮不能代替组件体系，染色不能代替光照融合，测试通过不能代替全角色全场景视觉验收。

审阅包括未提交的 UI_ART_REVIEW_1109、UI_ART_FIXES_1109、27 个已修改文件及审查截图，并参考仓库外 ../docs/design_scope_1109 的两份原始讨论。原讨论中的用户选择继续有效：3 套开局、180 补购、支持岗位按情况需要电脑、确定性摸鱼结合发现提醒、初期固定槽位。其旧 HUD 占位图、“绝不遮挡”“天然向后兼容”等推论不再作为实施依据。源码与当前 OFFICE_O0_O3 / OFFICE_O4_FIRST_LOOP 优先。

原 UI_ART_REVIEW_1109 是针对 0c41339 的历史只读报告；其截图不是本轮修改后的证据。报告中的 P0 是视觉优先级，不等于数据损坏或崩溃级缺陷。没有证据支持“与大型商业二次元游戏同等完成度”，只采纳其层级清晰、一致性与反馈原则。

## 3. 已接受的方向与待样板验证的视觉约束

### 3.1 题材、材质与角色

定位为 **温暖的工作室世界，克制清晰的界面，伙伴承担主要情感表达**。场景提供暖意，UI通过字级、对齐、分组与状态建立秩序，角色提供亲近感。保留 AI Village 原版12名角色身份、服饰、骨架与授权来源；协调背景、角色与家具的细节密度，避免用统一灰黄滤镜抹掉身份色。

- 背景：暖自然光、柔和材质、明确可用地板；背景中的吧台/机柜等为建筑装饰，不冒充可交互设施。后续新背景将“装修固定件”和“购买实体”分层设计。
- 家具：现代木质办公家具，圆润体块、轻描边、三段明暗与接触阴影。左上柔光只是制作基准，最终光向服从所在场景；避免烘焙强光与环境染色重复叠加。保留SVG结构/交互层，可用有来源的少量纹理或绘制层补充；由整屏样板决定媒介与质量，不提前全量替换。
- 角色：现有 scale/headY 是逐角色视觉校准，不能称为头身比归一化证明。以可见身体 bbox、眼线、坐姿脸部遮挡共同验收；头饰与尾巴不作为身体等高依据。
- 环境色：本轮一次性轻暖 tint 是基线；后续按场景与时段设置统一环境参数，暗场不牺牲脸部明度。禁止每个骨骼层累乘染色。
- 地板锚点保持(0,0)，前/角色/后遮挡层与共用1920×1080世界相机保留。不能为了画面漂亮删除可购买实体或更改可工作容量。

### 3.2 工位等级与玩法表达

| 等级 | 剪影约束（最终造型待样板） | 机制口径 |
|---|---|---|
| 基础 / Tier 0 | 小木桌、简单木椅/凳、旧单屏，无灯带与装饰堆叠 | 已实施：工作精力额外+2，产出无加成 |
| 标准 / Tier 1 | 整洁暖木桌、网布椅、单屏；小型桌灯/绿植作次级差异 | 已实施：执行/负责人WP +10%，按实际产出计资源；不写成Tier II |
| 高级 / Tier 2 | 升降结构、更完整人体工学椅、横竖双屏 | 仅视觉预留；价格、效率与摸鱼概率需独立规则验收 |
| 豪华 / Tier 3 | 更宽围合桌面、曲面屏/多屏、明显高端椅型 | 仅视觉预留；不提前卖无效果数值 |

标准工位上的 +10% 是岗位相关产出加成，不能表达成所有角色的速度、质量或稳定收益。预估为条件预测；结算后另给实际结果。精力预警使用图形+文字，闪电仅作视觉提示，<35 是 UI 提醒阈值，不改变领域疲劳规则。服务器外壳明确无算力效果，摸鱼/休闲恢复当前未开放。

### 3.3 UI 视觉规范

- 材质候选：小面积HUD可使用深胡桃透明衬底，阅读面板以中性暖白/深灰稳定承载文字，布置工具使用深色工具面。具体透明度、边框、圆角和阴影待三张整屏样板一起确认，不再默认所有入口都是同等权重的黑金胶囊。保留全屏世界和按需浮窗，普通开窗不改变镜头。
- 装饰黄铜、键盘焦点、选中指示分开定义语义token；焦点须在实际底色上清楚可辨。鼠尾草绿表达正向收益，危险红表达风险。选中/风险同时用形状、图标或文字表达，不能只靠颜色。
- 当前 tokens.css 是运行时颜色源：--paper、--solid、--primary-bg/--primary-ink、--fs-*。文档不再维护另一套虚构 token 名。后续删除重复局部值时逐组件回归，不能一次性用通配覆盖。
- 正文14–16px，说明12–14px，11px限于非关键标签；价格、风险、操作结果不得用11px。标题现用系统楷/衬线回退为过渡方案，正式字体需有许可、中文/英文覆盖、离线加载与体积记录后再纳入。
- 主行动实心、一个区域一个主行动；次行动描边/纸面，危险行动含明确文字。主按钮不得仅用透明文字。全部控件都有默认、悬停、键盘焦点、按下、选中、禁用、忙碌与错误状态。
- 保留语义化原生 select/details/meter，先统一外观与交互。仅因“原生控件像网页”就重造下拉框不成立；自定义版本必须先证明键盘、读屏、触控和长列表体验不退化。
- 动效120–180ms，状态转换可观察，禁用动画时信息仍完整；不引入反复闪烁与无意义漂浮数字。

### 3.4 布局与手机策略

桌面以场景为主，抽屉按需显示。手机采用“场景局部观察 + 显式定位 + 返回全景”，不把12人强行缩进390px。相机切换不暗中筛选人物；定位伙伴/任务须由用户触发，普通开窗与派遣确认不隐式跳镜头。当前裁切与分区renderable过滤列入VF1/VF3整改。手机资金/额度保留紧凑可读摘要，低频操作优先收入更多；上一轮679px以下隐藏资源仅为临时防溢出，不是最终信息架构。

槽位布置继续是固定锚点；显示选择器作为键盘与裁切兜底，支持收起工具。不要承诺所有家具与浮窗永不重叠；验收的是可找到、可选中、可取消、可保存，以及关窗后可看清世界。
