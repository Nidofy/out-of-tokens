# Tier 2 / Tier 3 工位视觉参考

原型仅归档，不加载到正式办公室或商店；不赋予容量、效率或数值效果。每级有 back/front 两张透明 PNG，280×240。图像像素 (140,200) 对应世界地板 (0,0)，等价 viewBox 为 -140 -200 280 240。参考合成顺序：back → 坐姿角色 → front。

Tier 2 保留升降立柱、人体工学椅、横竖双屏；Tier 3 保留围合桌面、曲面多屏与高端椅。屏幕置右；前层中央预留面部矩形 [105,20,165,80] 内 alpha<96。back 的椅背在角色后方，不能按 front 的遮脸条件判断。

manifest.json 记录 alpha>=96 命中包围框、面部区域最大 alpha、像素/世界锚点、尺寸、字节数和 SHA256。原始母版在 ../masters；导出仅做透明边界裁切、等比缩放和画布定位。视觉参考并非可直接替换现有 SVG 的成品；正式接入仍须依真实坐姿骨架校准两层尺度、逐角色验证脸部与指针命中。当前未改动既有工位或其封板契约。
